# Codex conversation exports

These exports contain the original visible user and assistant messages from the
two Codex chats used for this assignment. Message text is not edited, cleaned up,
or summarized. Markdown adds role and turn headings for navigation; the matching
JSON files retain message IDs, content, and attachment references.

| Chat | Readable transcript | Structured transcript |
| --- | --- | --- |
| Create minimal Python project skeleton | [Markdown](01-project-development.md) | [JSON](01-project-development.json) |
| Review TaxDome test task code | [Markdown](02-code-review.md) | [JSON](02-code-review.json) |

Each export states its cutoff in UTC. These are snapshots of the conversations,
not live links. User messages, assistant replies, progress updates, and
clarification questions are included. Tool execution logs, internal reasoning,
and system/developer instructions are outside the scope of these user/assistant
conversation exports.

Original attachment paths are preserved in message text. Copies are supplied
below so reviewers can open them without access to the author's computer.
[attachments.json](attachments.json) maps the original paths to repository files.
